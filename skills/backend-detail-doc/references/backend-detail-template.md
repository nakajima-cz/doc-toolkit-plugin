## セクション記述ルール

1. 全セクションでコード参照（ファイルパス#行番号）を必ず併記する
2. テーブル内の「箇所」「検証箇所」「生成箇所」「発生箇所」「取得箇所」「定義箇所」は全てコード参照で記載
3. リクエスト例・レスポンス例・メッセージ例は実装から推定可能な範囲で記載。推測部分は `/* 推定 */` とコメント
4. 処理フローのステップ分割は実装の論理的なまとまりに基づく。1ステップは概ね10-30行程度を目安とする
5. 「なし」の場合も省略せず「なし」と明記する（後から追記漏れと区別するため）
