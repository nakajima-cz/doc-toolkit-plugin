# DBモデルドキュメント生成スキル

## 事前準備

作業開始前に、以下の設定ファイルを読み込んでください:

- `.claude/project-config.md` — モデルファイル位置、テーブル構成

プロジェクト内のORM（Object-Relational Mapping）モデルを解析し、モデルごとに設計書を生成します。

## モデルファイルの場所

`.claude/project-config.md` の「バックエンド構成」の「モデルファイルディレクトリ」を参照してください。
一般的には以下のパターン:

```
backend/layer/models/
├── model1.rb
├── model2.rb
├── ... (多数のモデルファイル)
├── abstract/        # 抽象クラス（継承元として参照）
├── base/            # 基底クラス
└── concern/         # 関心事（共通機能）
```

## 解析ワークフロー

### Step 1: モデルファイルの読み込み

1. 対象モデルファイルを Read する
2. 継承元クラスを特定（`< ApplicationRecord`, `< Abstract::Cart` 等）
3. 継承元が abstract/ にある場合は、そのファイルも Read する
4. include している concern/ や module も確認する

### Step 2: 各要素を抽出

以下を順番に解析する:

#### 2-1. 基本情報
- クラス名
- テーブル名（自動マッピング or 明示的設定）
- 継承クラス
- includeしているConcern/Module
- ファイルパス（相対パス）

#### 2-2. 定数・設定
- enum 定義（ステータス値等）
- 定数定義
- テーブルマッピング設定

#### 2-3. アソシエーション
- リレーション定義（has_many, belongs_to, has_one 等）
- オプション（外部キー、クラス名、削除動作等）

#### 2-4. バリデーション
- バリデーション定義
- 条件付きバリデーション

#### 2-5. コールバック
- データ永続化時のコールバック

#### 2-6. スコープ
- スコープ定義（クエリのショートカット）

#### 2-7. クラスメソッド
- クラスメソッド定義
- 引数、処理概要、戻り値をコード参照（行番号）付きで記載

#### 2-8. インスタンスメソッド
- インスタンスメソッド定義（private含む）
- 各メソッドについて:
  - 目的・概要
  - 引数（型・デフォルト値）
  - 戻り値
  - 主な処理ステップ（行番号付き）
  - 副作用（DB更新、キャッシュ操作、外部API呼び出し等）

### Step 3: 保存

`.claude/project-config.md` の「ドキュメント出力設定」に従って保存してください。
一般的なパターン:

- ファイル名: `backend/docs/models/{ClassName}.md`
- 抽象クラス: `backend/docs/models/abstract/{ClassName}.md`
- Concern: `backend/docs/models/concern/{ModuleName}.md`

## 品質チェックリスト

ドキュメント作成後、以下を確認する:

- [ ] 全メソッドにファイルパス・行番号が記載されている
- [ ] `private` メソッドも含まれている（省略しない）
- [ ] 継承元のメソッドはオーバーライドしているもののみ記載
- [ ] enumの値と意味が説明されている
- [ ] アソシエーションのオプションが記載されている
- [ ] 複雑な処理は箇条書きでステップを分解している
